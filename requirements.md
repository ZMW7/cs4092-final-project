# Requirements
This system will be used as a backend for an e-commerce system.

- Each customer shall have an ID, several addresses (one of which is to be marked as the "primary address,"), and credit / debit cards on file that can be used as payment (one of these cards should be desginated the 'prefered' payment method).
- Every address should have a country, city, state / province, address line 1, address line 2, and postal code.
- Customers can make purchases. Each purchase can involve multiple items, and uses one form of payment. 
- Every purchase is associated with a delivery to a certain address, and every delivery should have a status, as well as an estimated time of delivery. Each purchase should have a unique ID.
- Customers should be able to rate products that they have purchased.
- Products are to be listed on the online marketplace by sellers. When a customer makes a purchase, payment (except for the service's cut) is sent to the seller.
- Customers should be able to report products for breaking the site's terms of service (for example, the e-commerce site prohibits false advertising). Each report should be given a unique ID.
